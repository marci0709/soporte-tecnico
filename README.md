# Sistema de gestión de solicitudes de soporte técnico

Aplicación web en React para registrar y administrar solicitudes de soporte.

## Tecnologías
React · Vite · Tailwind CSS v4 · shadcn/ui

## Funcionalidades
- Registro de solicitudes con validación de campos
- Cambio de estado (pendiente, en proceso, resuelta)
- Eliminación de solicitudes
- Filtros por estado

## Estructura de componentes
- App: estado y coordinación
- SolicitudForm, FiltrosSolicitudes, ListaSolicitudes, SolicitudItem

## Ejecutar
npm install
npm run dev
